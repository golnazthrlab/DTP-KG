# Data exploration

[DrugBankExplore.ipynb](DrugBankExplore.ipynb) presents the four paper figures.
Use the shared datasets generated by
[DataPreparation.ipynb](../../data/DataPreparation.ipynb).
Follow the [setup instructions](../../README.md), then fill in the notebook paths.

## Redraw the figures

After running the path cell in `DrugBankExplore.ipynb`:

```python
from dtpkg.drugbank.generate_modality_coverage_figure import generate_modality_coverage
from dtpkg.drugbank.generate_level_dist_figure import generate_level_distribution
from dtpkg.drugbank.generate_mesh_freq_cov_figures import generate_mesh_panels

generate_modality_coverage(COVERAGE_CSV, OUTPUT_DIR)
generate_level_distribution(ANNOTATIONS_CSV, OUTPUT_DIR)
generate_mesh_panels(ANNOTATIONS_CSV, OUTPUT_DIR)
```

## Regenerate the analysis inputs

Run the [data preparation notebook](../../data/DataPreparation.ipynb) with the
source files and input formats described in the [data guide](../../data/README.md).
Then use the same `DATA_DIR` in `DrugBankExplore.ipynb` and set `REGENERATE = True`.
The notebook reads the saved modality-coverage and expanded MeSH annotation tables.

Continue with [network construction](../02_network_construction/README.md).
